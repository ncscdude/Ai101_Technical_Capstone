# ADR-003: Use Field Presence As The PASS/WARN/FAIL Gate

## Status

Accepted.

## Context

The system needs a deterministic rule for deciding whether a canonicalization run
returns PASS, WARN, or FAIL. A confidence threshold is tempting, but confidence
scores vary by model and are not calibrated across Claude, Copilot, or future
agent runs.

## Decision

Use field presence and reviewability, not numeric confidence, as the gate.

- PASS: approved document type and all required fields are sourced from the document.
- WARN: file is readable, but one required value is inferred, missing, or ambiguous.
- FAIL: file is empty, unreadable, or not one of the approved document types.

## Consequences

This makes the MVP deterministic and testable. It does not prove every extracted
value is semantically correct, so `source_hint` and `extraction_snippet` are
required for review.
